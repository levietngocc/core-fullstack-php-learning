# Day 01 — PHP Core Mapping

> Syntax không phải để nhớ, mà để build backend.

## Main backend flow

```txt
Client / React / Browser
--- HTTP request --->
PHP / Laravel Backend
--- input
--- sanitize
--- validate
--- process
--- output / response
--->
Client / React / Browser
```
